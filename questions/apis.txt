

Base URL: `http://localhost:8001/api/v1`

### Health
- `GET /healthcheck`
  - no auth required
  - returns app health

---

### Users
- `POST /users/register`
  - multipart form-data: `avatar`, optional `coverImage`
  - body: `fullName`, `email`, `username`, `password`
- `POST /users/login`
  - body: `email` / `username`, `password`
- `POST /users/logout`
  - auth required
- `POST /users/refresh-token`
  - refresh token flow
- `POST /users/change-password`
  - auth required
- `GET /users/current-user`
  - auth required
- `PATCH /users/update-account`
  - auth required
- `PATCH /users/avatar`
  - auth required, multipart form-data: `avatar`
- `PATCH /users/cover-image`
  - auth required, multipart form-data: `coverImage`
- `GET /users/c/:username`
  - auth required
- `GET /users/history`
  - auth required

---

### Videos
- `GET /videos`
  - auth required
- `POST /videos`
  - auth required, multipart form-data: `videoFile`, `thumbnail`
- `GET /videos/:videoId`
  - auth required
- `DELETE /videos/:videoId`
  - auth required
- `PATCH /videos/:videoId`
  - auth required, optional multipart form-data: `thumbnail`
- `PATCH /videos/toggle/publish/:videoId`
  - auth required

## Notes
- All routes under users, `/videos`, `/comments`, `/likes`, `/playlist`, `/subscriptions`, `/tweets`, and `/dashboard` generally require JWT auth.
- The only open route is `GET /healthcheck`.
- Use `http://localhost:8001` if your .env still has `PORT=8001`.

If you want, I can also create a short Postman collection or curl examples for the main endpoints.
